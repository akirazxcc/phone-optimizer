# Оптимизатор (Phone Optimizer)

Android-приложение для Poco F6 (HyperOS / Android 14), работает и на других телефонах с Android 11+.

**Что умеет**

| Вкладка | Функции |
|---|---|
| Очистка | Поиск и удаление мусора в хранилище (`.tmp`, `.log`, `.bak`, миниатюры, забытые APK, пустые папки). Очистка кэша всех приложений и кэша в `Android/data` |
| Приложения | Отключение и включение системных приложений, запрет работы в фоне, force-stop, удаление для пользователя 0 и возврат. Список проверенных «лишних» приложений Xiaomi с отметками «Безопасно» и «Осторожно» |
| ADB | Готовые оптимизации (анимации, перекомпиляция ART, TRIM, закрытие фона) и своя команда. Любую команду можно скопировать как `adb shell ...` для ПК |

Все ADB-функции выполняются на самом телефоне, ПК не нужен: приложение использует [Shizuku](https://github.com/RikkaApps/Shizuku). Очистка мусора в хранилище работает и без неё.

## 1. Сборка APK (без Android Studio)

1. Создайте на GitHub пустой репозиторий.
2. Загрузите в него все файлы этого проекта:
   ```bash
   git init && git add . && git commit -m "init"
   git branch -M main
   git remote add origin https://github.com/<вы>/<репозиторий>.git
   git push -u origin main
   ```
3. Откройте вкладку **Actions** → **Build APK**. Сборка стартует сама после push (или нажмите **Run workflow**).
4. Через 3–6 минут откройте завершённый запуск и скачайте артефакт **PhoneOptimizer-debug**: внутри `app-debug.apk`.
5. Установите APK на телефон (разрешите установку из неизвестных источников).

Локально: `gradle assembleDebug` (нужны JDK 17 и Android SDK 34).

## 2. Настройка Shizuku на Poco F6 (один раз)

1. Установите Shizuku: <https://github.com/RikkaApps/Shizuku/releases> (или из Google Play).
2. Включите режим разработчика: **Настройки → О телефоне → 7 раз нажмите на «Версия OS»**.
3. **Настройки → Дополнительные настройки → Для разработчиков** → включите **Отладку по USB** и **Беспроводную отладку** (нужен Wi-Fi).
4. Откройте Shizuku → **Запуск через беспроводную отладку** → **Сопряжение**. В «Беспроводной отладке» нажмите **Сопряжение по коду** и введите код в уведомлении Shizuku. Затем нажмите **Запустить**.
5. Откройте «Оптимизатор»: вверху нажмите **Выдать** и разрешите доступ.

Замечания:
- После перезагрузки телефона Shizuku нужно запускать заново (шаг 4, сопряжение повторять не надо).
- Если команды `pm` падают с `SecurityException`, в «Для разработчиков» включите **Отладку по USB (настройки безопасности)**. Для этого на Xiaomi нужен вход в Mi-аккаунт.
- Если не выдаётся доступ ко всем файлам для очистки: **Настройки → Приложения → Оптимизатор → Доступ ко всем файлам**.

## 3. Как отключать системные приложения безопасно

- Начинайте с фильтра **Рекомендуемые**: там только известные «лишние» сервисы Xiaomi.
- Отключение (`pm disable-user`) **полностью обратимо**: фильтр **Отключённые**, переключатель.
- «Удалить для пользователя» (`pm uninstall -k --user 0`) тоже обратимо, кнопка **Вернуть удалённое приложение** или команда:
  `adb shell cmd package install-existing <имя.пакета>`
- Критичные пакеты (`systemui`, лаунчер, настройки, телефон, Google Play Services, провайдеры, клавиатуры) приложение менять не даёт.
- Приложения с пометкой **Осторожно** (например, `com.xiaomi.joyose`) могут влиять на игровые режимы и ограничение нагрева: отключайте по одному и проверяйте работу.

## 4. Команды, которые использует приложение

| Действие | Команда |
|---|---|
| Кэш всех приложений | `pm trim-caches 999G` |
| Кэш в Android/data | `rm -rf /sdcard/Android/data/*/cache/*` |
| Закрыть фон | `am kill-all` |
| Анимации | `settings put global window_animation_scale\|transition_animation_scale\|animator_duration_scale <0\|0.5\|1.0>` |
| Компиляция ART | `cmd package compile -m speed-profile -a` (сброс: `cmd package compile --reset -a`) |
| Фоновый dexopt | `cmd package bg-dexopt-job` |
| TRIM | `sm idle-maint run` |
| Отключить / включить | `pm disable-user --user 0 <pkg>` / `pm enable --user 0 <pkg>` |
| Запрет фона | `cmd appops set <pkg> RUN_IN_BACKGROUND ignore` и `RUN_ANY_IN_BACKGROUND ignore` |

## Структура проекта

```
app/src/main/java/dev/optimizer/phone/
  MainActivity.kt   вход, тема
  Ui.kt             экраны Compose (Очистка, Приложения, ADB)
  MainViewModel.kt  состояние и действия
  Shell.kt          выполнение команд через Shizuku
  Cleaner.kt        поиск и удаление мусора
  Apps.kt           список приложений, защищённые пакеты и список «лишних»
  Tweaks.kt         список ADB-оптимизаций
.github/workflows/build.yml   сборка APK в облаке
```

Чтобы добавить свою оптимизацию, добавьте `Tweak(...)` в `Tweaks.kt`. Чтобы расширить список «лишних» приложений, допишите пакет в `Debloat.known` в `Apps.kt`.
